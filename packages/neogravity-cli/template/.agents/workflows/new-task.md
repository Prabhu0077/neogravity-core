# /new-task

1. Ask the user for a one-line goal if it was not given.
2. Write the task into `.knowledge/tasks/active_tasks.md` under "Up next" with:
   - **Goal:** one sentence
   - **Done when:** a check anyone can run (a command, a page, a test)
   - **Notes:** links or files that matter
3. Do not start the work until the user says go.
